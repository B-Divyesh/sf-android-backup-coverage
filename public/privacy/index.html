Product policy

Privacy

Last updated: August 28, 2026.

Your file list stays here

Folder details, settings, and saved checks stay in this browser. The app does not send file names, sizes, dates, or check results to a data server.

Demo separation

The demo uses a separate browser database whose name starts with demo:. It never reads or changes your real saved checks. Starting for real deletes the demo database.

Exports

JSON and CSV exports are created in your browser. The browser saves them only when you choose an export button.

Network use

The app requests its own files to load and update. It uses no advertising, analytics, tracking scripts, runtime CDN, account service, or payment service.

Your control

Use “Erase local data” to remove saved folder details and checks. Browser site-data controls can also remove them.

Contact

Questions can be sent through sociobot.in (external site).
